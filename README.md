# page_report: shareable results page

A static, single-page report (`index.html`) summarising `model_results_analysis/` and `loss_attribution_analysis/`. It has no external dependencies (no JavaScript libraries, fonts or CDN), supports light/dark mode, and works on phones.

## Contents

| Path | What |
|---|---|
| `index.html` | the report, generated by `build.py` |
| `build.py` | builds `index.html` from `data/`; standard library only; prints the key numbers as `CHECK` lines |
| `data/` | the CSVs the page is computed from, copied unchanged from the analysis folders (table below) |
| `sources/` | the hand-written findings the page summarises, copied for reference. Their relative links point into the original repo layout and may not resolve here. |

**Rebuild** after updating any CSV: `python3 build.py`

## Where each data file comes from

| `data/` file | Original |

| `corpus_predictability_{qwen,pythia}.csv` | `loss_attribution_analysis/outputs/corpus/predictability_{qwen,pythia}/summary.csv` |
| `bench_{answer,segments,contrasts,link,sanity}.csv` | `loss_attribution_analysis/outputs/benchmark/{answer,segments,contrasts,link,items_sanity}.csv` |
| `corpus_format.csv` | `loss_attribution_analysis/outputs/format/format_docs.csv` |
| `answers_{content,contrasts,numbers,types}.csv` | `loss_attribution_analysis/outputs/answers/{answer_content,answer_contrasts,number_faithfulness,answer_types}.csv` |

**Not computed from these files:**
- the seed-noise band (0.16–0.49 points), from the finephrase paper's Table 21, as quoted in `sources/LIGHTEVAL_N1000.md`;
- the setup facts (architectures, mix, generator, steering layer and α);
- the qualitative description of the unsupported-number examples (`loss_attribution_analysis/outputs/answers/NUMBERS.md`);
- the temperature-baseline note (`sources/RUN_PLAN.md`).

## Publishing on GitHub Pages

1. Put the contents of this folder at the root of a repository, or in a `docs/` folder. Include `.nojekyll` so GitHub serves the files as they are.
2. In the repository settings, go to **Pages** and choose the branch and folder (`/` or `/docs`).
3. The page is then at `https://<user>.github.io/<repo>/`.

The `data/` CSVs total under 1 MB.
